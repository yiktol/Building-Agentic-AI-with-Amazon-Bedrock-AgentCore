---

## Slide 23 — Question 1: Answer

![M01 slide 23](images/M01/slide-23.png)

**Narration:**

> The correct answer is B, the requirement for cyclical decision-making with continuous adaptation. Let's review why. Option A, the need for a large language model, is incorrect, because the mere presence of an LLM does not make a system agentic; traditional applications use LLMs too. Option B is correct, because agentic AI is defined by its cyclical, adaptive decision-making, where the agent keeps working with its components until it gets the result right. That continuous adaptation and autonomy is exactly what sets it apart from a linear input-to-output system. Option C, faster response times, is incorrect, because performance improvements are not unique to agentic AI. And option D, cloud versus on-premises deployment, is incorrect, because deployment location is not a defining characteristic; both traditional and agentic AI run in many environments.

## Slide 25 — Question 2: Answer

![M01 slide 25](images/M01/slide-25.png)

**Narration:**

> The correct answer is B: framework or agent code, memory, tools, the large language model, and inter-agent communication. Let's review the others. Option A lists Runtime, Policy, Browser, Code Interpreter, and Identity; these are AgentCore services, not the essential architectural components of an agent. Option C lists observability, security, deployment monitoring, and evaluation; these are important considerations you must manage, but they are not the core building blocks. And option D lists several memory types; memory is critical, but it is just one of the five components, not the whole architecture. Option B is correct because it captures the five essential elements: the framework and code for orchestration, the LLM for reasoning, memory for context, tools for taking action, and inter-agent communication for collaboration.
