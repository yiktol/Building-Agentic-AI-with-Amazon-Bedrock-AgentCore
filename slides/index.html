Building Agentic AI with Amazon Bedrock AgentCore

Take agents from prototype to production — runtime, security, tools, memory, and observability with the AWS AgentCore service family.

About this course: a hands-on path to building production-ready agentic AI on AWS. You will start with the foundations of agentic systems and the Amazon Bedrock AgentCore services, then deploy agents on AgentCore Runtime with popular open-source frameworks. From there you secure agents with AgentCore Identity, extend them with tools through AgentCore Gateway and the Model Context Protocol, give them short- and long-term AgentCore Memory, and finally monitor and evaluate them in production with AgentCore Observability and Evaluations.
